# EyeQ Vision Care

**Live site:** https://vasiniks.github.io/eyedemo/

Cinematic scroll-driven homepage for EyeQ Vision Care, built with Vite, React, and GSAP. The app lives in [`V1/`](V1/).

## Develop

```sh
cd V1
npm install
npm run dev
```

## Deploy

Every push to `main` builds `V1/` and publishes it to GitHub Pages via [`.github/workflows/pages.yml`](.github/workflows/pages.yml).
